**The contract boundary is the repository checkout (decided r6, rule 12a).** MANDATE's failure
mode is "a closed finding can be reopened by one method call nobody counts" — a change to source
that a reviewed diff carries. Everything the checker can read in the checkout is in the contract
(rows above). Outside it, stated rather than hidden:

* **Machine state** — process environment (`CLIPPY_CONF_DIR`, `RUSTFLAGS`,
  `CARGO_ENCODED_RUSTFLAGS`, `CARGO_BUILD_RUSTFLAGS`, `CARGO_TARGET_*_RUSTFLAGS`), `$CARGO_HOME/config.toml`,
  and `.cargo/` directories above the checkout. No diff carries them and no reviewer sees them;
  rounds 4–5 showed that any list of them is incomplete (process variables, then Cargo `[env]`, then
  the user config), so a partial guard would claim a completeness it does not have. The r5
  environment guard was therefore withdrawn rather than extended. CI is the controlled environment:
  it sets none of these (M14). Its branch filter skipping slash-named branches is open finding
  `f-20260915-08`, not this task.
* **The gate command line** (`-D warnings`, no `-A`) is owned by the push skill and `test.yml`,
  which change only through reviewed diffs.
* **Dependency build scripts and proc macros** are dependency code whose versions `Cargo.lock`
  pins; the package's own `build.rs` is inside the contract (O3.13).
