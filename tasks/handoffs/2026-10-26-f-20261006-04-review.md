## Approach

### Late spawn is already on the drain

Production `Command::spawn` runs only after `pending_actors.insert` under `admission_coordination`, and only when that same critical section observed no cancellation. `terminate_all` cancels admissions, then awaits each unvisited pending termination. Application exit awaits `terminate_all` inside the existing shutdown budget. A cancelled admission never reaches `Command::spawn`. A spawn that won the race is owned by that awaited termination. When the termination succeeds, it removes the pending entry and any child that spawn created is reaped before `drain_matching` returns. When the reap fails, the attempt has still been awaited, including a spawn that was still in flight at the snapshot, and the error is returned; `start_termination` keeps the unresolved owner in `pending_actors`, later snapshots skip that visited generation, and shutdown still calls `exit(0)`. ## Approach

### Late spawn is already on the drain

Production `Command::spawn` runs only after `pending_actors.insert` under `admission_coordination`, and only when that same critical section observed no cancellation. `terminate_all` cancels admissions, then awaits each unvisited pending termination. Application exit awaits `terminate_all` inside the existing shutdown budget. A cancelled admission never reaches `Command::spawn`. A spawn that won the race is owned by that awaited termination. When the termination succeeds, it removes the pending entry and any child that spawn created is reaped before `drain_matching` returns. When the reap fails, the attempt has still been awaited, including a spawn that was still in flight at the snapshot, and the error is returned; `start_termination` keeps the unresolved owner in `pending_actors`, later snapshots skip that visited generation, and shutdown still calls `exit(0)`. That retained owner is the failed-cleanup owner `d-20261014-07` already requires, not a spawn after the drain observed an empty snapshot.
