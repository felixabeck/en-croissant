# En Croissant — agent context

Chess GUI: Tauri v2 desktop shell (Rust) + React/TypeScript renderer. Felix's **fork**
(`origin` = `felixabeck/en-croissant`, `upstream` = the original project).

**`CLAUDE.md` in this directory is the canonical project context — read it first.** It carries the
repository layout, the gate mapping, the review lenses and the commit conventions. This file exists
because Codex and other non-Claude agents do not load `CLAUDE.md` automatically; it repeats only
what an implementing agent cannot afford to miss.

## Non-negotiables

- **Do not stage, commit, push, or deploy.** Leave your work in the tree; the orchestrating agent
  reviews the diff and commits it under its own committer name. This overrides any standing
  commit-your-own-work instruction in your global configuration.
- **The worktree may be shared with other agents.** Never revert, reformat, or restage anything you
  did not change. Read `git status` yourself rather than assuming the tree is clean or dirty.
- **`src/bindings/generated.ts` is generated by Specta and never hand-edited.** Regenerate with
  `pnpm bindings:generate`; `pnpm bindings:check` fails if the checked-in file differs by a byte.
- **Coverage floors and bundle budgets are ratchets.** Never lower a floor or rewrite a baseline to
  make a gate pass — see `docs/coverage.md`.
- **Formatting and linting are `oxfmt` / `oxlint`** (`pnpm format`, `pnpm lint:fix`), not
  Prettier/ESLint.
- **User-facing strings go through i18next** (`src/translation/`), then `pnpm i18n:extract`.
- Widening a filesystem, HTTP or CSP scope in `src-tauri/capabilities/main.json` or
  `src-tauri/tauri.conf.json` is a security decision, not a build fix.

## Gates

`.agents/skills/push/SKILL.md` is the single source for which gate runs for which changed path.
Read it rather than guessing; the commands themselves live in `package.json` scripts.

## Verifying a visible change

`.claude/skills/verify-ui/SKILL.md` is the canonical contract; `.agents/skills/verify-ui/SKILL.md`
is its bridge for you. **Read it before verifying any UI change.** Chrome MCP cannot attach to the
Tauri webview, and `pnpm start-vite` plus a browser is not evidence — `TopBar.tsx` calls
`getCurrentWebviewWindow()` at module scope and the page crashes without a Tauri backend. Automated
proof is `pnpm test:e2e:container`, which runs the suite inside the pinned Playwright image so the
committed screenshots do not depend on which machine recorded them. Never re-record snapshots
natively.

## Findings you cannot fix here

A defect you find outside your assignment is not a question for Felix and not a chat note — it goes
on disk immediately. Write the complete `###` entry to a file with `**ID:** f-PENDING`, then run
`python3 scripts/findings.py file <path-to-entry-file>`. Never pick an id yourself, never edit
`tasks/findings.md` by hand. `python3 scripts/findings.py related --area <a> --file <p>` first, so
you extend an existing finding instead of filing a duplicate. The area vocabulary is a closed set in
the ledger header. Full contract: the "Findings ledger" section of `CLAUDE.md`.
